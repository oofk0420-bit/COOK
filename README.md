# 한끼짝꿍 🍳🥚

냉장고에 있는 재료만 알려주면, AI가 지금 만들 수 있는 요리를 추천하고 **완성까지 함께하는** 요리 초보(2030 자취생)용 AI 요리 파트너. 마스코트는 계란요정 **한끼요정**.

> **검색 없이 요리 끝까지 함께하는 AI 요리 파트너 — "없어도 괜찮아, 있는 걸로 충분해요."**

**2026 나는 Solo AI** 공모전 출품작 (부산정보산업진흥원 주최).

## 🔗 바로 써보기 (실제 배포)

### 👉 https://cook-nu-flax.vercel.app

브라우저에서 바로 실행되는 **실제 작동 서비스**입니다 (실제 AI 응답).

## 무엇을 해결하나

요리가 어려운 게 아니라, **유튜브·블로그·생성형 AI를 오가며 조리 흐름이 계속 끊기는 경험**이 어렵습니다.
한끼짝꿍은 그 끊긴 경험을 하나로 연결합니다 — **재료 추천 → 대체재 안내 → 조리 중 실시간 질문 → 완성**까지 검색 없이 한 흐름으로.

## 핵심 기능

- **재료 기반 추천**: 냉장고 재료를 고르면 AI가 지금 만들 수 있는 요리를 완성도(%)와 함께 추천
- **대체재 안내**: 부족한 재료는 대체 가능한 식재료로 안내해 요리를 포기하지 않게
- **AI 쿡모드**: 단계별 레시피 + 조리 중 궁금증을 **그 자리에서 실시간 질문**(검색 없이)
- **개인화·안전**: 알레르기 재료 배제 + 식성 반영 추천
- **무중단 설계**: 네트워크 오류 시 폴백 데이터로 서비스가 멈추지 않음

## 기술 구성

- **프론트엔드**: 바닐라 JS 단일 HTML SPA
- **AI**: Claude `claude-opus-4-8` (Anthropic Messages API)
- **아키텍처**: `SPA → Vercel 서버리스 프록시(api/chat) → Claude API`
  - **API 키는 서버 환경변수로만 보관**되어 클라이언트에 노출되지 않음
- **응답 처리**: 추천·판정은 JSON 고정 출력으로 화면 자동 구성 / 조리 중 질문은 자연어 응답
- **배포**: Vercel
