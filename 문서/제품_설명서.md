# 한끼짝꿍 — 제품 설명서 (사용 안내)

> 이 문서는 **한끼짝꿍이 어떤 앱이고, 각 화면이 어떻게 동작하는지**를 발표·시연용으로 정리한 것입니다.

- **접속 링크(실제 작동, AI 포함)**: https://cook-nu-flax.vercel.app
- **권장 환경**: 스마트폰 브라우저 (앱이 390px 세로 레이아웃이라 폰에서 가장 예쁩니다). 데스크톱에선 가운데 폰 카드 형태로 보입니다.

---

## 1. 앱 소개

한끼짝꿍은 **요리 초보를 위한 AI 요리 짝꿍**입니다. 캐릭터 "한끼요정"이 냉장고 속 재료로 지금 만들 수 있는 요리를 찾아주고, 없는 재료 대체법과 만드는 과정까지 함께합니다.

---

## 2. 화면별 사용법

### ① 첫 진입 — 온보딩
- 처음 열면 한끼요정이 나와 **사용법 3가지**(재료 넣으면 추천 / 없는 건 대체 / 막히면 질문)를 3초 안내합니다.
- "시작하기"를 누르면 홈으로 이동하며, 이후엔 다시 뜨지 않습니다.

### ② 홈
- **한끼요정 캐릭터 + 슬로건**.
- **🥚 라이브 AI 미리보기**: "냉장고에 뭐가 있어요?" 재료 칩(계란·김치·감자…)을 누르면, 그 자리에서 AI가 "🤔 찾는 중…" 후 **지금 만들 수 있는 요리를 완성도 %와 함께** 보여줍니다. 목록의 요리를 누르면 바로 상세로 이동.
- **오늘 한끼**: "재료로 찾기" / "메뉴가 정해졌어요" 두 시작 버튼.
- **요즘 이거 많이 만들어요**: 인기 요리 카드가 가로로 흐르는 마퀴.

### ③ 재료로 시작 (발견)
- 냉장고에 있는 재료를 칩으로 입력 (예: 계란, 김치, 대파).
- **"이걸로 뭘 만들지?"** → AI가 지금/거의 만들 수 있는 요리 3~4개를 완성도 순으로 추천.
- 재료가 1~2개뿐이어도 그 재료만으로 되는 가장 간단한 요리를 알려줍니다.

### ④ 요리명으로 시작 (판정)
- 만들고 싶은 요리를 입력 (예: 김치찌개).
- AI가 **내 재료로 만들 수 있는지 판정** → 완성도 %, 있는 재료, **없는 재료 + 대체법**, 만드는 법.
- 아래에는 카테고리별 인기 요리 그리드도 있습니다.

### ⑤ 결과 화면
- **완성도 %** (게이지) · 조리시간 · 난이도(⭐) · 설거지 정도.
- **🤖 AI 추천 이유**: "냉장고에 있는 ○○을 바로 활용할 수 있어요" 등.
- **🤖 AI 분석 카드**: 냉장고 활용도·조리시간·설거지·**대체 가능 재료 수**.
- **있는 재료 / 없는 재료(대체법)** · 🛒 사야 할 재료 담기.
- **필요한 재료** 목록: 각 재료에 **"없어요" 버튼** → 짝꿍이 대체법 제시.
- ⚠️ **알레르기 경고**: 로그인 후 알레르기 설정 시 위험 재료 안내.

### ⑥ 쿡모드 (만드는 법 · 과정 동행)
- **재료 준비 화면** → **단계별 전체화면 안내** (일러스트 + 미니 요정).
- 각 단계에 **"🤔 이거 맞나요?"** → "이런 상태면 잘 되고 있는 거예요" 안심 신호.
- **🥺 도와줘요!** 버튼 → 상황별 해결책 + **🤖 짝꿍에게 직접 질문** 입력창.
  - 예: "불이 너무 센 것 같아요" → AI가 **현재 요리·단계 맥락으로** 초보 눈높이 답변.
- 완성 시 "맛있게 완성됐어요!" + **🏠 홈으로 돌아가기**.

### ⑦ 둘러보기 (커뮤니티)
- 사용자들이 올린 레시피를 **인스타그램 피드**처럼 탐색.
- 상단 **🔥 오늘 HOT** 랭킹 캐러셀 · 인기 레시피 / 인기 작성자 카드.
- 검색(레시피·재료·작성자) · 카테고리 필터 · 최신/인기 정렬.
- 카드마다 **❤️ 좋아요 · 🔖 저장 · 🕐 시간**, 작성자 **팔로우**, 탭 시 레시피 상세.
- ※ 현재 커뮤니티 콘텐츠는 **기능 시연용 샘플**이며, 좋아요·저장·팔로우는 실제로 카운트됩니다.

### ⑧ 내 정보 (마이페이지)
- **로그인** (닉네임만으로 시작 — 프로토타입).
- **커뮤니티 스탯**: ❤️좋아요 · 👤팔로잉 · 🔖저장 (둘러보기에서 실제 누른 것 카운트).
- **기록**: 만든 요리 · 써본 재료 · 내 레시피 (실제 카운트).
- **🚫 알레르기·못 먹는 재료** / **🥗 식성** 설정 → **AI 추천에 실제 반영** (위험 재료 제외, 취향 우선).
- 최근 만든 요리 · 레시피북 · 내 레시피 등록.

## 3. 핵심 동작 원리 (발표용 요약)

- **AI는 매번 추론합니다** — 미리 저장된 DB를 꺼내는 게 아니라, 내가 넣은 재료를 읽고 그때그때 요리를 만들어냅니다.
- **대체재는 앱이 먼저** 예상해서 제시합니다 ("없어요" 버튼).
- **과정 중에도 AI가 옆에** — 막히면 자유롭게 물어보면 맥락 맞춰 답합니다.
- **나를 기억합니다** — 알레르기·식성·기록이 저장돼 새로고침해도 유지되고, AI가 그걸 반영합니다.
- **연결이 안 되면** 내장 데모로 앱이 멈추지 않습니다 (시연 안정성).

## 5. 시연 추천 흐름 (영상·발표용)

1. 첫 진입 온보딩 → "냉장고에 뭐 있어요?"
2. 홈에서 재료 칩 탭 → AI가 요리 찾아주는 순간 (**AI가 작동한다**)
3. 결과에서 **"없어요"** → 대체법 뜨는 순간 (**핵심 가치**)
4. 쿡모드 → **"불이 센 것 같아요"** 물어보면 AI가 맥락 맞춰 답 (**과정 동행**)
5. 마이페이지에서 **알레르기 설정** → 추천이 실제로 바뀜 (**개인화·안전**)
6. 마무리: **"없어도 괜찮아, 있는 걸로 충분해요."**
