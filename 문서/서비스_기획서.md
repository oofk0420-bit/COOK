## 1. 한 줄 정의

**"냉장고에 있는 재료만 알려주면, AI가 지금 만들 수 있는 요리를 찾아주고 없는 재료는 어떻게 대체할지까지 알려주는, 요리 초보를 위한 나만의 AI 요리 짝꿍."**

- 서비스명: **한끼짝꿍**
- 캐릭터: **한끼요정** (계란 요정 — 흰자 몸통 + 노른자 얼굴)
- 슬로건: **"없어도 괜찮아, 있는 걸로 충분해요."**
- 형태: 모바일 웹앱 (실제 배포·작동)

## 2. 문제 정의 — 왜 만들었나

자취를 시작한 2030 요리 초보에게 요리는 매일 부딪히는 벽입니다.

1. **레시피는 넘치는데, 정작 내 냉장고 기준이 아니다.**
   "집밥"을 검색하면 이상적인 레시피가 나오고, **있지도 않은 치킨스톡·굴소스**를 넣으라고 합니다. 유행 따라 다들 같은 특수재료를 요구하죠.
2. **없는 재료를 어떻게 대체하는지 아무도 안 알려준다.**
   "치킨스톡 없는데 어쩌지?" → 결국 요리를 포기합니다.
3. **하다가 "이게 맞나?" 물어볼 곳이 없다.**
   불세기, 익힘 정도, 간 — 애매한 순간마다 불안하고, 검색해도 "적당히"라고만 나옵니다.
4. **결정 피로.**
   "오늘 뭐 먹지"부터가 막막합니다. 빈 검색창 앞에서 뭘 물어야 할지도 모릅니다.

> **핵심 인사이트:** 요리 초보에게 필요한 건 "완벽한 레시피"가 아니라, **"지금 내가 가진 것으로 뭘 할 수 있는지"를 함께 정해주고 과정을 옆에서 도와주는 존재**다.

## 4. 솔루션 — 4가지 축

| 축 | 내용 |
|---|---|
| **① 내 재료가 기준 (방향의 전환)** | "이상적 레시피"가 아니라 "**내가 가진 재료**"에서 출발. 지금 만들 수 있는 것을 완성도 순으로 추천. |
| **② 대체재를 먼저 준다** | 재료마다 "없어요" 한 번이면 짝꿍이 대체법 제시. 특수재료 때문에 포기하지 않게. |
| **③ 과정을 함께한다** | 쿡모드에서 단계별 안내 + "이거 맞나요?" 실시간 확인. 요리 중 막히면 **AI에게 자유롭게 질문**. |
| **④ 나를 기억하고 맞춰준다** | 알레르기·식성을 AI가 반영해 위험 재료를 빼고 취향에 맞춰 추천. 설정·기록은 저장돼 유지. |

---

## 5. 핵심 기능

1. **재료로 시작 (발견)** — 냉장고 재료 입력/사진 → AI가 지금 만들 수 있는 요리 3~4개 추천 (완성도 %).
2. **요리명으로 시작 (판정)** — 만들고 싶은 요리 입력 → 내 재료로 되는지 판정 + 없는 재료 대체법.
3. **대체재 안내** — 재료별 "없어요" → 실제 요리 지식 기반 대체안 (예: 굴소스 → 간장+설탕).
4. **🤖 AI 분석 카드** — 냉장고 활용도·조리시간·설거지·대체 가능 재료 수를 데이터로 요약.
5. **쿡모드 (과정 동행)** — 전체화면 단계별 안내 + "이거 맞나요?" 성공 신호 + **실시간 AI 질문** ("불이 센 것 같아요" → 맥락 맞춰 답변).
6. **둘러보기 (커뮤니티)** — 사용자 레시피 피드, 인기 레시피·작성자, 좋아요·저장·팔로우.
7. **알레르기·식성 개인화** — 설정하면 AI가 위험 재료를 제외하고 취향 반영.
8. **레시피북·기록** — 저장한 레시피, 만든 요리, 통계 (모두 실제 카운트, 저장 유지).
9. **온보딩** — 첫 진입 시 3초 사용법 안내.

## 6. 차별성

### vs 기존 레시피 앱 (만개의레시피 등)
- 기존: 레시피 **DB 검색** (내 재료 무관, 대체 안내 없음).
- 한끼짝꿍: **내 재료 기준 AI 판단** + 대체재 + 과정 동행.

### vs 그냥 ChatGPT에 물어보기
> 엔진은 같은 AI(Claude)를 씁니다. 차별점은 **"문제를 어떻게 정의하고 어떤 경험으로 감쌌나"** 입니다 — 이것이 "AI 활용"의 핵심.

- **방향이 반대**: ChatGPT는 "레시피 알려줘" → 이상적 레시피. 한끼짝꿍은 "내 냉장고에 이거 있어" → 지금 가능한 것.
- **대체재 선제 제공**: ChatGPT는 다시 물어봐야 답함. 한끼짝꿍은 "없어요" 버튼으로 먼저 예상.
- **과정 동행**: ChatGPT는 텍스트 한 번 던지고 끝. 한끼짝꿍은 단계별 + 실시간 질문.
- **개인화·안전**: 알레르기를 매번 말할 필요 없이 AI가 자동 반영.
- **결정 피로 제거**: 빈 입력창이 아니라 "냉장고에 뭐 있어요?"로 먼저 이끌어줌.

**한 문장 포지셔닝:**
> "ChatGPT는 **레시피를 알려주고**, 한끼짝꿍은 **지금 내 냉장고로 뭘 할 수 있는지 함께 정해줍니다.**"

## 7. AI 활용 (공모전 핵심)

- **모델**: Claude (Anthropic) — 가장 유능한 모델로 실시간 호출.
- **AI가 실제로 하는 일**:
  1. 내 재료를 읽고 **지금 만들 수 있는 요리를 생성** (DB 검색 아님, 매번 추론).
  2. 요리 실현 가능성 **판정** + 없는 재료 **대체법** 생성.
  3. 조리 중 자유 질문에 **현재 요리·단계 맥락으로** 실시간 답변.
  4. 알레르기·식성을 반영해 **안전하고 개인화된** 추천.
- **"1인 AI 활용" 주제 적합성**: 팀 규모 제품이 아니라, **자취생의 일상 문제(끼니 해결)를 AI로 재설계**한 사례. 개발·데이터 구축·기획을 1인이 AI를 활용해 완성.

## 8. 기술 구조

```
[사용자 브라우저(앱)]  ──재료/질문──▶  [Vercel 서버리스 프록시]  ──▶  [Claude AI]
        ▲                                     (API 키를 환경변수로 은닉)         │
        └──────────────  추천/답변  ◀──────────────────────────────────────────┘
```

- **프론트엔드**: 단일 HTML + Vanilla JS (프레임워크 無, 가볍고 빠름). 이미지·아이콘 인라인.
- **배포**: Vercel (정적 호스팅 + 서버리스 함수). GitHub 푸시 시 자동 재배포.
- **AI 프록시**: `/api/chat` 서버리스 함수가 API 키를 서버 환경변수로 숨기고 대신 호출 → **키가 브라우저·소스에 절대 노출되지 않음** (보안).
- **데이터**: 로그인·설정·기록을 브라우저 localStorage에 저장 (같은 기기에서 유지).
- **폴백 설계**: AI 연결이 안 되는 환경에선 내장 데모 데이터로 앱이 멈추지 않게 (시연 안정성).

## 9. 로드맵 (향후)

- **백엔드·실 DB 커뮤니티** (Supabase): 실제 사용자 인증, 레시피 등록/저장/랭킹.
- **냉장고 사진 인식**: 사진 한 장 → AI가 재료 자동 추출 (비전 활용).
- **개인화 심화**: 조리 이력 기반 취향 학습, 주간 식단 제안.
- **음성 안내**: 손이 바쁜 조리 중 음성 단계 안내.

## 10. 기대 효과

- 요리 초보의 **"오늘 뭐 먹지 → 포기 → 배달"** 악순환을 **"있는 걸로 해먹기"** 로 전환.
- 특수재료·조리 지식 장벽을 낮춰 **자취생의 자립적 식생활** 지원.
- **AI를 일상에 실질적으로 활용**하는 모범 사례 — 검색·챗봇을 넘어 "맥락을 아는 동행자"로.
